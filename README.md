# Ehab Thaer — Defensive Security Portfolio

A bilingual (AR/EN) React portfolio focused on SOC, Detection Engineering, and DevSecOps.

## Tech
- React + Vite
- CSS (custom theme)
- lucide-react icons

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deploy to GitHub Pages
```bash
npm run deploy
```
